Simple Calculator 🧮

A basic Python calculator that performs addition, subtraction, multiplication, and division.

Features

Addition (+)

Subtraction (-)

Multiplication (*)

Division (/)

Handles division by zero

Handles invalid operators

Accepts decimal numbers

Requirements

Python 3.x

How to Run

Make sure Python is installed on your computer.

Save the program as calculator.py.

Open a terminal in the project folder.

Run the following command:

python calculator.py

How It Works

The program asks the user to enter:

The first number

An operator (+, -, *, or /)

The second number

It then performs the selected mathematical operation and displays the result.

Example
Simple Calculator
Enter first number: 10
Enter operator (+, -, *, /): *
Enter second number: 5
Answer: 50.0

Supported Operations
Operator	Operation
+	Addition
-	Subtraction
*	Multiplication
/	Division
Error Handling

The calculator handles:

Division by zero

Invalid operators

Example:

Enter first number: 10
Enter operator (+, -, *, /): /
Enter second number: 0
Answer: Cannot divide by zero

Project Structure
simple-calculator/
│
├── calculator.py
└── README.md

Note

Make sure the subtraction condition is written as:

elif operator == "-":
    answer = num1 - num2
